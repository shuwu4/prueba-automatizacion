# Prueba técnica - Analista de Automatización

## Tecnologías
- Node.js
- JavaScript

## Ejecución
npm install
npm start

## Flujo
1. Consulta el catálogo.
2. Identifica productos con stock bajo.
3. Obtiene el tiempo estimado de reposición.
4. Calcula la urgencia.
5. Ordena los productos.
6. Genera una notificación con las prioridades principales.
